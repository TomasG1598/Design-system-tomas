# Design System — Tomás Gil Gómez

Librería de componentes UI construida con HTML, CSS y JavaScript puro,
sin frameworks ni dependencias externas.

## 🌐 Ver en vivo
https://tomasg1598.github.io/Design-system-tomas/

## 📦 Componentes incluidos
- **Tokens** — Variables CSS: colores, tipografía, espaciado, sombras
- **Colores** — Paleta completa con códigos hex copiables al clic
- **Tipografía** — Escala tipográfica con fuente Inter
- **Botones** — 5 variantes con estados hover, activo y deshabilitado
- **Inputs** — Campos con estados normal, focus, error y deshabilitado
- **Cards** — Componente reutilizable con animación hover
